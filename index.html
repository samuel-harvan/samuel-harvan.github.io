The shape of
the work.

I'm a mathematics student at the University of Waterloo who likes the whole stack — from the CAN frames moving between microcontrollers to the interface someone actually clicks.

That range is deliberate. At MCAP Financial I built a full-stack expense-reporting platform and an OCR pipeline that reads twenty thousand documents a year. At UW Formula Electric I write embedded C for the control units in a racecar. Before either, I taught fifteen-plus new programmers Java and Python while tuning a competition robot's drivetrain into something that could win.

Different problems, one habit: understand the system end to end, then make it measurably better.
